# Local development

1. XAMPP Apache + MySQL/MariaDB must be running.
2. Run `database\run_setup.bat` once.
3. Run `start-localhost-3000.bat`.
4. Open `http://localhost:3000`.

Development test account:
- Username: `admin`
- Password: `ChangeMe123!`

The app uses PHP's built-in server on port 3000, while Apache can remain running separately.
